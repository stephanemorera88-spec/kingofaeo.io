# kingofaeo.io

One static page for Stephane Morera, King of AEO. No build step. GitHub Pages serves this repository at https://kingofaeo.io/.

This domain is a dated experiment (EVOIX aeo-lab EXP-010): one exact-match domain, one page, no press release, with the prediction written before the page went live and the result published either way.

## Edit and deploy
1. Change `index.html`.
2. Push to `main`. Pages rebuilds in about a minute.
3. Do not delete `googlef29c36bcf91ecf61.html` (Search Console verification) or the 32-character `.txt` file at the root (IndexNow key).
